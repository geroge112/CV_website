# Interactive Portfolio Website

Interactive portfolio and CV website built with React and Vite.  
The project presents my CV, technical skills and portfolio projects through a responsive UI, dynamic project pages, reusable components and animated sections.

Live website: https://geroge112.github.io/CV_website/

## Overview

This project is my personal portfolio website created to support IT job applications and present my frontend development progress. It includes a structured CV section, project showcase, detailed project pages and a modern responsive layout.

The website is built as a data-driven frontend application where project content is stored separately and rendered through reusable components.

## Tech Stack

- React
- Vite
- JavaScript
- Tailwind CSS
- Framer Motion
- React Router
- GitHub Pages

## Features

- Responsive personal CV website
- Dynamic project pages with route `/project/:slug`
- Data-driven project rendering from `src/data/projects.js`
- Reusable project cards and UI sections
- Project showcase with detailed descriptions
- Animated page transitions using Framer Motion
- Mobile-friendly layout
- GitHub Pages deployment

## Project Structure

- `src/components` — reusable UI components
- `src/pages` — main website pages
- `src/data` — project data and content
- `src/layouts` — layout components
- `src/styles` — styling files
- `src/animations` — animation logic
- `src/assets` — static assets
- `src/api` — mock API layer
- `src/hooks` — custom hooks
